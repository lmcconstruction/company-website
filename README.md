# LMC Construction Website

A Next.js site for LMC Construction, ready to deploy on Vercel.

## Run locally
npm install
npm run dev

## Deploy
Push this to a GitHub repo, then import it in Vercel (vercel.com -> Add New -> Project).
Once deployed, connect your domain in Vercel's Project Settings -> Domains, then add
the DNS records Vercel gives you into your Wix domain's DNS settings.
